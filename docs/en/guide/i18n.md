# Internationalization

Components carry some copy of their own: weekday names in the calendar, "Confirm / Cancel" in Modal, "Loading / No more" in Loadmore, "No data" in Empty. All of it resolves through one locale config.

`zh-Hans` (Simplified Chinese, the default) and `en` ship built in.

## Switching language

<PlatformTabs>

<template #uniapp>

```js
// main.js
import uviewPlus, { registerLocale } from '@/uni_modules/uview-plus'
import en from '@/uni_modules/uview-plus/libs/i18n/en.json'

registerLocale('en', en)
uni.setLocale('en')
```

Built-in copy updates immediately after `uni.setLocale()`.

</template>

<template #uniappx>

```ts
// main.uts
import { registerLocale } from '@/uni_modules/uview-ultra/libs/i18n/index.uts'

registerLocale('en')
uni.setLocale('en')
```

</template>

## Registering a language pack

A pack is a flat key-value map. Japanese, for example:

```json
{
  "up.modal.confirmText": "確認",
  "up.modal.cancelText": "キャンセル",
  "up.loadmore.loadmoreText": "もっと見る",
  "up.loadmore.loadingText": "読み込み中…",
  "up.loadmore.nomoreText": "これで終わりです",
  "up.empty.text": "データがありません",
  "up.calendar.weekdays": ["日", "月", "火", "水", "木", "金", "土"]
}
```

Register it, then switch:

```js
import ja from './locales/ja.json'

registerLocale('ja', ja)
uni.setLocale('ja')
```

::: tip Partial packs are fine
Packs merge over the default, and missing keys fall back to `zh-Hans`. To change a handful of strings, ship a pack with only those keys.
:::

## Your own copy stays yours

All of the above covers **built-in component copy** only. The `title`, `text` and `placeholder` values you pass in are application copy: handle them with your project's own i18n solution (`vue-i18n`, `react-i18next`, `flutter_localizations`) and pass the result down as a prop:

```vue
<up-button :text="t('common.confirm')" type="primary" />
```

## Dates and numbers

The time formatter takes a format string and is locale-independent:

```js
uni.$u.timeFormat(Date.now(), 'yyyy-mm-dd hh:MM')   // 2026-09-03 14:30
uni.$u.timeFrom(Date.now() - 3600_000)              // an hour ago
```

The relative wording produced by `timeFrom()` does follow the active locale.
