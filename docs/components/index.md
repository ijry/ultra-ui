## 怎么读组件文档

每个组件页面的结构都是一样的：

- **平台徽标** — 页面顶部，灰色表示该平台暂未实现，点击可切换当前平台。
- **平台用法** — 标签页形式，每段代码都直接摘自对应平台示例工程里的真实代码，并标注了来源文件。
- **API** — 属性、事件、插槽，提取自 uview-plus 源码。各平台移植时保留了同名属性，因此这份表格对八端通用。
- **各平台源码** — 该组件在每个仓库中的具体文件位置。

平台选择是全站共享的：在任意一处切换平台后，其他页面的标签页会保持同一个选择，并记在浏览器本地存储里。
