# 国际化

组件内部有一部分自带文案：日历的星期名、Modal 的"确认 / 取消"、Loadmore 的"加载中 / 没有更多了"、Empty 的"暂无数据"等。这些文案走同一套 locale 配置。

内置 `zh-Hans`（简体中文，默认）与 `en`（英文）两种语言。

## 切换语言

<PlatformTabs>

<template #uniapp>

```js
// main.js
import uviewPlus, { registerLocale } from '@/uni_modules/uview-plus'
import en from '@/uni_modules/uview-plus/libs/i18n/en.json'

registerLocale('en', en)
uni.setLocale('en')
```

`uni.setLocale()` 之后所有组件的内置文案会立即切换。

</template>

<template #uniappx>

```ts
// main.uts
import { registerLocale } from '@/uni_modules/uview-ultra/libs/i18n/index.uts'

registerLocale('en')
uni.setLocale('en')
```

</template>

<template #reactnative>

```tsx
import { UP } from 'ultra-ui-rn'

UP.setConfig({ locale: 'en' })
```

</template>

<template #taro>


</template>

## 注册自定义语言包

语言包是一份扁平的键值表。以日语为例：

```json
{
  "up.modal.confirmText": "確認",
  "up.modal.cancelText": "キャンセル",
  "up.loadmore.loadmoreText": "もっと見る",
  "up.loadmore.loadingText": "読み込み中…",
  "up.loadmore.nomoreText": "これで終わりです",
  "up.empty.text": "データがありません",
  "up.calendar.weekdays": ["日", "月", "火", "水", "木", "金", "土"]
}
```

注册后即可切换：

```js
import ja from './locales/ja.json'

registerLocale('ja', ja)
uni.setLocale('ja')
```

::: tip 只覆盖部分键
语言包会与默认包合并，缺失的键回落到 `zh-Hans`。所以只想改几句文案时，语言包里只写那几个键就够了。
:::

## 业务文案不走这套

上面这套只管**组件内置文案**。你自己传进组件的 `title`、`text`、`placeholder` 属于业务文案，应该用项目自己的 i18n 方案（`vue-i18n`、`react-i18next`、`flutter_localizations` 等）处理，然后把结果作为属性传入：

```vue
<up-button :text="t('common.confirm')" type="primary" />
```

## 日期与数字格式

时间格式化工具接受一个格式串，与 locale 无关：

```js
uni.$u.timeFormat(Date.now(), 'yyyy-mm-dd hh:MM')   // 2026-09-03 14:30
uni.$u.timeFrom(Date.now() - 3600_000)              // 1小时前
```

`timeFrom()` 的相对时间文案会跟随当前 locale。
